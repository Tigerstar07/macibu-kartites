# 11 Izmantotie avoti

Avoti apskatīti 2026. gada 28. oktobrī. Tie izmantoti dokumentācijas struktūrai un konkrētu tehnisko risinājumu pārbaudei. Tie nav skolas individuālo noformēšanas prasību aizstājēji.

## A1 Latvijas programmēšanas mācību materiāli

[Skola2030 par programmēšanas patstāvīgo darbu](https://www.skola2030.lv/vecakiem-un-skoleniem/tehnologijas/programmesanas-eksamena-darba-paraugs-un-programma-augstakaja-limeni) uzsver programmatūras izstrādes dzīves cikla posmus, kodu un dokumentāciju. [Programmēšanas I materiālā par risinājuma īstenošanu](https://mape.gov.lv/api/files/F72124A0-7535-4526-B621-9AC9BA33B39A/download) iekļauta prasību specifikācija, kļūdu meklēšana, testēšana un lietotājam saprotams ceļvedis. Šeit izmantotas šīs dokumentu daļas, nevis pieņēmums par konkrētu eksāmenu vai skolas vērtējumu.

## A2 Dokumentācijas struktūra

[Diátaxis sākuma ceļvedis](https://www.diataxis.fr/start-here/) nošķir mācību piemērus, darbību ceļvežus, tehnisko atsauču informāciju un skaidrojumus. Projektā palaišana un lietotāja darbības ir ceļvežos, API un datu modelis atsauču sadaļās, bet tehnoloģiju pamatojums skaidrojuma sadaļā.

## A3 Autentifikācija un datubāze

[FastAPI JWT un paroļu jaukšanas ceļvedis](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/) izmantots, pārbaudot Argon2 paroļu jaucējvērtības, PyJWT un servera lietotāja pārbaudi. [SQLAlchemy SQLite dokumentācija](https://docs.sqlalchemy.org/en/20/dialects/sqlite.html#foreign-key-support) un [SQLite ārējo atslēgu apraksts](https://www.sqlite.org/foreignkeys.html) izmantoti, pārbaudot ārējo atslēgu ieslēgšanu katrā savienojumā.

## A4 Atkārtošanas algoritms

[SuperMemo SM-2 sākotnējais apraksts](https://www.super-memory.com/english/ol/sm2.htm) ir algoritma atskaites avots. [Anki mācīšanās dokumentācija](https://docs.ankiweb.net/manual/studying) izmantota kartīšu mācīšanās pieejas salīdzinājumam. Projekta punktu formulas un sliekšņi noteikti pēc paša projekta koda.

## A5 Projekta pirmkods un pārbaudes

[Tigerstar07/macibu-kartites repozitorijs](https://github.com/Tigerstar07/macibu-kartites) un [pārskatītais komits 10886bd](https://github.com/Tigerstar07/macibu-kartites/commit/10886bd) ir projekta darbības un izmaiņu atskaites punkti. Testēšanas rezultāti iegūti lokāli šajā pārskatē. Avotiem nepiedēvēti testi vai funkcijas, kuras tie neapliecina.
